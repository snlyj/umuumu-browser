# 手写的 Baseline Profile（没有设备可录；有设备后用 :baselineprofile 模块录一份真的，见 baselineprofile/README.md）
#
# 标志：H = 热（AOT 编译）  S = 启动路径（R8 据此把这些方法排在 dex 前面，冷启动少读页）  P = 启动之后用到
# 以前所有 com.yuka.cutebrowser 的方法都标成 HSP：S 失去意义（dex 重排什么也排不出来）。
# 现在：整个 App 的方法都是 H+P（照样预编译，滑动/开面板第一次不会解释执行），
# 只有冷启动到「首页画出来 + 第一个网页开始加载」这条路径上的才加 S。
#
# 通配符：** 跨包/跨层，* 只在一层里；通配符在 AGP 构建时按 APK 里真实存在的类和方法展开。
